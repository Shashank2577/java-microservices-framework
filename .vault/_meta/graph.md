# Graph hints (for Obsidian)

Obsidian's graph view renders the wiki-links between notes. To get the most signal:

- **Click a node** to see its backlinks panel (Obsidian → Settings → Core Plugins → Backlinks).
- **Filter the graph by tag** in the graph-view settings (e.g., show only `#drift` to see open drifts).
- **Color nodes by tag** to distinguish decisions (blue), drifts (red), debugging (orange), etc. — set under graph-view → Display → Color groups.
- **Local graph** (Cmd-click a note → "Open local graph") shows just the neighborhood of one note — great for "what touches a specific component?".

The vault is small at first. The graph becomes informative around ~30 notes.
