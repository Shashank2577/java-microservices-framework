## Session summary

This session was the third pass, driven by an external research finding ("don't reinvent — adopt where proven prior art exists") and an honest critique of the previous two passes. Net additions:

**Three new oversight skills** (32 framework skills total):
- `java-adversarial-drift` — separate read-only Claude session, no commit authority, runs weekly + pre-release to find drift the productive session missed.
- `java-framework-metrics` — explicit success criteria for the framework itself (outcome metrics, leading indicators, review cadence, Goodhart-resistant choices).
- `java-human-review-ritual` — daily / per-PR / weekly / quarterly human-in-the-loop checkpoints to prevent the closed-loop failure mode.

**Framework validator** (`tools/validate_framework.py`):
- Validates skill frontmatter (name + description required).
- Validates `lib/jabrena/...` paths in skills resolve.
- Validates vault note frontmatter against per-type schemas.
- Validates Obsidian-style wiki-links resolve to existing notes.
- Validates coverage thresholds are consistent (95% / 90% / 98% / 85%) across all skills that mention them.
- Best-effort secret-leak detection (gitleaks is authoritative in CI).
- Output: exit 0 on clean run, exit 1 with per-issue report otherwise. Verified currently clean.

**CI workflows**:
- `.github/workflows/validate-framework.yml` — runs the Python validator + lychee link check + markdownlint + frontmatter JSON-schema check, weekly on Mondays + on every PR touching the framework.
- `.github/workflows/ci.yml` — Gradle build with Postgres service + gitleaks.

**First real reference module** — `platform/building-blocks/domain-primitives/`:
- `TenantId` (record + `STANDARD` constant + validation)
- `Money` (record + currency-aware scaling + arithmetic + same-currency guard)
- `Result<T, E>` (sealed; `Success`/`Failure`; `map`/`flatMap`/`orElseThrow`)
- Tests for each, aiming at 100% line + branch
- Module README + `package-info.java` Javadoc
- Compiles against `gradle/libs.versions.toml`; no version literals

**Gradle scaffold** at repo root:
- `settings.gradle.kts` — includes the first building-block, comments mark sprint-2 modules
